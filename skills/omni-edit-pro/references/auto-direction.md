# Choose a treatment from the source

Use Auto when no designated or automatically classified reference applies and the user has not explicitly requested Manual. Honor explicit mode instructions and resolve a material conflict when one contradicts a required reference. The main entries proceed to inspection without compulsory format/style questions. Resolve initial file roles, constraints and authority through [Selection](selection.md); finalize the output set after the necessary inspection and before production dispatch. Use [Reference analysis](reference-analysis.md) when the user actually supplies a reference. For unlabeled videos, run Selection's metadata/decoded-frame classifier first; input order or aspect ratio alone does not establish a reference.

Auto chooses one supported treatment for each inspected source. Evolving meaningful graphics, animation and suitable transitions are the default throughout the edit in every composition; adapt their pace and amplitude to the topic and scene. It does not promise virality, maximize effects or invent a universal style for every genre. Keep the free/local workflow, actual per-source teams and one timeline owner from [Workflow](workflow.md) and [Batch and teams](batch-teams.md).

## Inspect the material that determines the choice

Use decoded frames, normal-speed motion and actual listening in the opening, middle, ending, scene changes and difficult passages. Record the selected streams, display aspect ratio, duration, existing cuts, readable interface/detail regions, camera movement, people, dialogue, intentional quiet and existing design. A filename, transcript or isolated thumbnail cannot establish the genre or a suitable treatment by itself.

Describe what viewers need to follow and which evidence supports that conclusion. Classify by scene when the video changes form; a single file may contain a presenter, screen demonstration and travel sequence. Record observed content, time span, confidence with reason, protected content and uncertainty. “Unknown” is an acceptable finding. Do not force uncertain material into a confident genre label.

If there is no speech, record “no dialogue observed” with reviewed coverage rather than inventing a transcript or narration. Silent screen recordings need action/shot cues; silent landscapes need scene and movement cues. Do not assume every source has a presenter, require a speaker cutout where no appropriate subject exists, or add invented explanations. Inspect the actual audio streams before concluding that a file is silent. If source access or playback is unavailable, produce only the supported provisional plan and identify the missing evidence; no verified edit exists yet.

## Resolve the independent decisions

Keep these fields in the job plan even when one compact plan contains them all:

| Decision | Resolution and evidence |
| --- | --- |
| Creative mode | Reference for a designated reference; otherwise Auto; Manual only on explicit request. Record the user's instruction or default. |
| Explicit constraints | User's destination, audience, brand, runtime, preservation and prohibited changes; identify unresolved contradictions. |
| Output shape | Clear user override, then explicitly selected preset default, then applicable reference, then source display aspect ratio. In Auto without a reference, the reference step is absent. |
| Composition | Explicit selected style remains fixed. Otherwise choose Split, Cutout, Overlay or Adaptive from observed scenes and content needs. |
| Treatment | Source-specific type, palette, graphics, motion, transitions, audio and pacing principles, with inspected topic/source/subject/clothing and contrast evidence. |
| Motion coverage | Full-duration source/output intervals, meaningful graphic development, settled readable elements, transition purpose and any justified short reading holds or explicit user stillness overrides. |
| Editing authority | Separate allowances for trim, reorder, crop/reframe, speed changes and full-screen B-roll replacement; record the instruction and scope for each. |
| Output set | The exact requested variants and which instruction supplied each choice, before creating rendering jobs. |

A later clear instruction changes only the named decision. Invoking vertical-overlay and saying “horizontal instead” resolves horizontal Overlay; it does not invite choosing a different composition. An automatically matched preset supplies no user instruction. All retains its default two orientations times Split/Cutout/Overlay, six outputs per source; Adaptive is not a seventh variant. Honor explicit narrowing such as All, horizontal only, giving three per source. Preserve these contracts when Auto directs the treatment inside a preset.

With no stronger instruction, retain the source's display aspect ratio after rotation and pixel aspect ratio are accounted for, including square or other shapes. Do not infer a vertical destination merely from a short duration or an energetic subject. Explicit presets retain their named 16:9 or 9:16 default. Fit the full source and reflow graphics when source and output shapes differ; a shape choice by itself does not authorize cropping. Select sensible delivery resolution from source detail and destination rather than automatically upscaling.

Preserve original duration, dialogue, order, pauses, speed and framing by default. The same protection applies to meaningful non-speech actions, performance timing and existing scene relationships. A treatment choice supplies no permission to trim, reorder, crop, retime or replace footage with full-screen B-roll. “Best judgment” alone does not remove these protections. A concrete shorter/highlights/montage request grants necessary selection and composition within its stated scope; record that authority and proceed without asking again. It does not grant unrelated cropping, speech acceleration or other changes. Resolve a shorter runtime only when it conflicts with explicit protected content such as “keep every word”; do not silently violate either instruction. Map permitted edits through the single timeline described in [Transcription and sync](transcription-sync.md).

## Select a source-specific evolving treatment

Start with the footage's working strengths. Choose purposeful graphic development while preserving intentional quiet, reactions, actions and existing effective design. Quiet scenes can use low-amplitude highlights or progressive context; they are not an automatic exemption to motion coverage. Long frozen cards with an entrance and exit fade, or an unchanged source-native frame alone, do not meet the default. Keep labels stable for reading while other graphic parts progress; record a short reading hold's interval, reason and next state. Explicit user stillness instructions override the default for their recorded scope. These are starting points based on observed evidence, not compulsory templates:

| Observed material | Useful initial treatment | Preserve or verify |
| --- | --- | --- |
| Lesson or explanation | Clear hierarchy, progressive mechanisms/diagrams and active-step emphasis with settled labels | Qualifications, explanation time, speech and relevant gestures |
| Interview or documentary | Quiet contextual reveals, restrained emphasis and carefully chosen supporting visuals | Answer meaning, reactions, original context and intentional pauses |
| Screen or product demonstration | Action-linked callouts, progressing step indicators and unobtrusive captions | Interface text, cursor, actual action order and the result of each step |
| Travel, action or music-led footage | Let shot relationships, movement, geography and real sound guide contextual graphics and transitions | Meaningful scene sequence; montage, beat cuts and retiming require their own authority |
| Fiction, performance or polished existing edit | Quiet source-grounded graphic development and suitable visual handoffs | Dramatic timing, intentional silence, continuity and existing design choices |
| Mixed material | A coherent visual vocabulary with scene-specific layouts | Smooth scene handoffs and each scene's protected content |

Adaptive is a composition choice in the main workflow for material that does not fit a presenter layout. It can preserve full-frame scenes, arrange a screen demonstration with safe callouts, or use scene-specific layouts while retaining a coherent treatment. It does not imply arbitrary effects, authorize shot replacement/cuts/crops, override an explicit preset or alter All's six default variants. See [Editing styles](editing-styles.md) and [Layouts and effects](layouts-effects.md) for composition limits.

Overlay can be appropriate when the intact source image is already useful and there is safe space. Split is useful when explanation needs a distinct region and an actual presenter/subject remains readable. Cutout requires an appropriate real subject, suitable source detail and successful local extraction; use [Local cutouts](local-cutout.md). If an explicit Cutout request cannot work, report that variant's limitation and available verified alternatives; do not silently deliver another style under its name. Complete independent passing variants in a batch.

Write one selected treatment with a short reason supported by source intervals. Include a compact type hierarchy, palette/contrast evidence, graphic purpose/density, motion and transition vocabulary, full-duration coverage, audio approach, protected regions and relevant scene exceptions. Use [Visual planning](visual-planning.md) and [Motion design](motion-design.md) to turn those choices into source-anchored cues. No minimum effect count, B-roll percentage or fixed cut frequency applies; meaningful coverage is assessed over the whole edit. Decorative pulses, random template swaps and unauthorized cuts/zoom/retiming do not satisfy it. Follow [Editing styles](editing-styles.md) for geometry, including portrait presenter placement.

Choose the palette per video from its topic, inspected source imagery/background, subject and clothing, tone, and applicable user/brand/reference instructions. Record background, text, accent and semantic-color choices and test luminance/color separation over changing footage, bright/dark passages and moving clothing. Use a backing treatment or revise colors when necessary without changing evidentiary colors. Do not default automatically to blue/navy or cycle palettes arbitrarily. Blue is valid when instructed, supported by an applicable brand/reference, or justified by the actual subject matter and tested contrast.

For a batch, inspect and direct every source independently. Different subjects need content-specific visual metaphors, graphic mechanisms, motion and transition timing; recoloring or retitling one cloned effects sequence is insufficient. Share a requested brand system and compatible resources when appropriate, and allow variants of the same source to share its treatment. Record each source's own evidence, palette decisions, cues and review rather than forcing every video to look different or assuming one approved video certifies the rest.

## Handle low confidence without inventing a brief

When genre or taste is uncertain but the content and permissions are clear, choose a restrained, reversible treatment: preserve the source, use readable typography and quiet action/meaning-linked graphic development, and avoid speculative assets or new cuts. Keep the coverage plan active without decorative filler or long frozen cards. State the uncertainty and what the preview will resolve. Do not require the user to choose from a speculative menu before inspecting supplied media.

Ask only when an unresolved fact materially prevents a permissible decision, such as ambiguous source/reference roles, conflicting explicit outputs, missing source access, or a runtime that cannot preserve protected content. A style preference alone can usually be addressed by one supported preview. Clear user overrides remain binding regardless of classification confidence.

### Worked example

The user asks: “Edit this silent square screen recording using your best judgment.” Inspection confirms a 1:1 display frame, an audio stream with no audible content in reviewed coverage, an interface task from 00:00–00:18 and important controls along the bottom. No reference, preset or shorter runtime is requested.

Choose Auto, retain 1:1 and duration, use Adaptive with the full interface intact, protect the bottom controls and plan action-grounded callouts, progressing step indicators and quiet focus transitions across the task in available space. Settle each instruction for reading while the next inspected action drives graphic development; choose colors from the actual interface and tested contrast. Record transcription as not applicable to the observed silent material. Trim, reorder, crop, speed changes and full-screen replacement remain unauthorized. Preview the busiest interaction at delivery size, verify the silent audio path, then check the full result. This is an illustrative decision record, not evidence of a rendered edit.

## Verify the chosen direction

Render a representative preview before expanding the design, usually 15–30 seconds or enough to show the hardest relevant scene, a dense moment and quiet graphic development or a justified short reading hold. Use actual source audio when present. Judge clarity, relevance, readable pacing, purposeful motion and palette/contrast at intended viewing size; inspect cursor/gesture visibility, caption accuracy and scene-specific risks. An independent reviewer checks the treatment against this source's stated brief, coverage plan and preservation constraints. A full-range genre label is not a quality verdict.

If the preview fails, simplify or revise the treatment and verify the changed passage. A technically successful render is not proof that the choice suits the content. Apply [Quality assurance](quality-assurance.md) to every full output, not only the preview. If motion, sound or full-output viewing is unavailable, mark the gap and keep the candidate needs-review in the working area. Only checked, reviewed exports enter `Final Output Videos` through [Delivery](delivery.md). Use [Evaluation](evaluation.md) before claiming comparative improvement over an earlier release.
